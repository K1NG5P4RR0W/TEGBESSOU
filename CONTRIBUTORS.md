## How to sign
1. Read `CLA.md`.
2. Open a pull request that adds one line to the table below with your real
   name (or legal entity), your GitHub handle, the CLA version, and the date
   (YYYY-MM-DD).
3. Your merged pull request is your signature — timestamped and recorded in the
   git history.
