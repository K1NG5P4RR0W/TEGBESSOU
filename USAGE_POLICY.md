# Usage Policy — TEGBESSOU

TEGBESSOU is an offensive security tool licensed under AGPL-3.0 (see `LICENSE`).

## Authorized use only
This tool is intended solely for:
- security assessments against systems for which you hold **explicit written
  authorization** (contractual engagement / SoW);
- **bug bounty** programs, strictly within their defined scope and rules;
- **training** environments you control (CTF, lab, intentionally vulnerable machines);
- **learning** and security research on systems you own.

## Prohibited
Any use against a system without authorization is illegal in most jurisdictions
and is **strictly prohibited**. The authors and contributors accept no liability
for illegal or abusive use (see the "AS IS" clause of the license).

## Built-in safeguards
By design, TEGBESSOU enforces: mandatory authorization before any action,
scope validation on every request, and an append-only, tamper-evident audit
log. These safeguards protect the operator as much as third parties — do not
bypass them.

## Reporting
For a vulnerability in TEGBESSOU itself, see `SECURITY.md`.
